# RipetizioniMatteoPiras
🎓 Sito di una pagina per ripetizioni di Informatica, Matematica e Fisica a Padova e online — HTML/CSS puro, pubblicato con GitHub Pages

## 🥚 Easter eggs

Il sito premia chi è curioso — cioè esattamente il tipo di studente giusto per le ripetizioni di Informatica:

1. Apri la **console del browser** (F12) → c'è un messaggio nascosto
2. Guarda il **codice sorgente** (Ctrl+U) → c'è un commento nascosto
3. Digita il **codice Konami** (↑ ↑ ↓ ↓ ← → ← → B A) → modalità sviluppatore

Realizzato in HTML, CSS e due righe di JavaScript — niente framework, niente build. ♪
